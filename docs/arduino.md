# Arduino

The Arduino sketch reads sensors and updates both displays. It does not currently implement the HTTP server or weather forecast.

```sh
cd arduino
./scripts/install-deps.sh
./scripts/build.sh
```

The same sketch can be opened in Arduino IDE. See the [Arduino README](https://github.com/bygregonline/esp32-sample1/blob/master/arduino/README.md) for dependencies and upload instructions.
